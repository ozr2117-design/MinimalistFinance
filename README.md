# 极简记账 (MinimalistFinance)

一个免费、无广告、纯净本地运行的 Android 极简记账应用。1:1 还原经典记账交互，彻底解除商业版 VIP 限制。

---

## ✨ 核心特性

1. **支出 · 收入 · 转账 1:1 极简交互**：
   - **支出**：精简五大核心大类（衣、食、住、行、其他）；
   - **收入**：六大经典分类（工资、生活费、收红包、外快、股票基金、其它）；
   - **转账**：双账户互转卡片，支持一键对调、手续费与优惠计算。
2. **四大账本体系（无 VIP 限制，无限自由新建）**：
   - 默认预设：**日常消费账本**、**境内投资账本**、**境外投资账本**、**长期储蓄账本**；
   - 支持无限自建专属项目账本（如“欧洲旅行”、“新房装修”）；
   - 账本间数据物理隔离，支持独立核算与全局合并大盘。
3. **自定义计算器软键盘**：
   - 内置加减算术运算（边算边记）；
   - 提供「再记」与「保存」双操作流。
4. **纯净双模外观**：
   - 🌙 **夜间纯黑模式 (AMOLED Black)**
   - ☀️ **日间极简模式 (Crisp White)**
   - 🌓 **跟随系统**
5. **纯本地 SQLite 存储**：
   - 数据完全保存在手机本地数据库，零服务器依赖，隐私绝对安全。

## 🚀 如何获取与编译 APK

### 方式 1：GitHub Actions 自动云端出包 (推荐，无需本地配置环境)
本项目根目录下已预置完整的工作流配置文件 `.github/workflows/build-apk.yml`：
1. 将当前工程代码推送到你的 GitHub 仓库；
2. GitHub 云端服务器会自动拉取 JDK 17 与 Android SDK 35 并在几分钟内完成编译；
3. 进入仓库的 **Actions** -> **Artifacts**，即可直接一键下载编译好的 `极简记账-app-debug.apk` 安装到手机！

### 方式 2：使用 Android Studio 本地编译
1. 打开 **Android Studio** (推荐 Koala 或更高版本)；
2. 选择 **Open Project**，打开当前文件夹 `C:\Users\A\Desktop\others\A`；
3. 等待 Gradle 依赖同步完成；
4. 点击顶部菜单 **Build -> Build Bundle(s) / APK(s) -> Build APK(s)**；
5. 编译完成后，在 `app/build/outputs/apk/debug/` 目录下即可直接拿到 `app-debug.apk`。
