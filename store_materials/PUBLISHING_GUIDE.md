## 二、上架必备资质三件套：怎么准备？

### 1. 开发者实名认证（个人身份）
- **准备材料**：
  1. 身份证正反面彩色照片（四角完整、无反光、无遮挡）；
  2. 手持身份证照片或手机端人脸活体识别；
  3. 常用手机号码（用于接收审核短信）；
  4. 同名国内银行储蓄卡（用于部分平台的小额打款验证，通常 0.01~0.1 元认证）。
- **注册网址**：
  - 酷安开发者中心：`https://developer.coolapk.com`
  - 小米开放平台：`https://dev.mi.com`
  - 华为开发者联盟：`https://developer.huawei.com`
  - vivo 开发者平台：`https://developer.vivo.com.cn`
  - OPPO 开放平台：`https://open.oppomobile.com`

### 2. 工信部 App 备案（2023年9月起新规）
> **不要害怕备案！现在的流程已经完全平台化、傻瓜化。**
- **操作方式**：
  无需自己去工信部提交，您在应用市场（如小米、华为）上传 APK 后，后台会自动引导您进入 **「App 免费代备案通道」**：
  1. 自动读取您的包名 `com.minimalist.finance` 和我们为您生成的 SHA256 签名指纹；
  2. 您在线确认个人身份信息与 App 简介；
  3. 进行电信人脸核验与短信核验（工信部会发一条验证码短信到手机，点击短信链接输入即可）；
  4. 省通信管理局审核（通常 3~7 个工作日下发备案号，格式如：`粤ICP备xxxxxx号-1A`）。

### 3. 软件著作权登记证书（软著 / CP）
- **如果你想先快速上线（0 成本、最快当天）**：
  - **直接首发「酷安」**！酷安不需要软著，只需在后台勾选版权承诺即可上架，先让朋友和第一批极客用户用起来。
  - 同步通过 GitHub / Gitee 的 Release 页面提供官方直链下载。
- **如果你想上架华为、腾讯等强制软著的平台**：
  - **官方免费申请**：登录「中国版权保护中心」（`https://www.ccopyright.com.cn`），按照指引提交软件基本信息、前 30 页与后 30 页代码、用户说明书，免费办理（周期约 30~45 个工作日）。
  - **淘宝/代理加急**：若急需，可在电商平台找正规代办机构办理加急件（按天计费，3~10 工作日）。

## 三、避开审核驳回的高频 5 大雷区（必看）

### 雷区 1：应用分类选错被归为“金融理财”
- ❌ **错误做法**：在应用分类中选择「金融 - 理财 / 信贷 / 股票」。
  - *后果*：各大平台会自动触发国家金融类监管审核，要求提供金融机构牌照、电信业务经营许可证（EDI/ICP）、数万元保证金，个人开发者直接被拒！
- ✅ **正确做法**：一律选择 **「工具 - 生活实用」** 或 **「效率 - 记账备忘」**！
  - 在应用介绍中突出“个人生活收支辅助记录”，规避金融交易属性。

### 雷区 2：敏感权限填写模糊或留空
- ❌ **错误做法**：在提交页面的权限使用说明中写“为了提供更好的服务”或空着不写。
  - *后果*：100% 被秒拒。
- ✅ **正确做法**：直接打开项目目录中的 `store_materials/PERMISSION_GUIDE.md`，将每一条权限对应的“官方标准申报文案”逐一复制粘贴进去！

### 雷区 3：没有可公开访问的《隐私政策》URL
- ❌ **错误做法**：不填，或填本地 `file:///` 路径。
- ✅ **正确做法**：各大平台后台强制要求输入一个外网可以直接访问的 HTTP/HTTPS 链接。
  - 推荐方案：直接使用项目中准备好的 `store_materials/PRIVACY_POLICY.html`，部署到您的 Gitee Pages 或 GitHub Pages，获得如下链接填入：
    `https://ozr2117.gitee.io/MinimalistFinance/privacy.html`
    或 `https://ozr2117-design.github.io/MinimalistFinance/privacy.html`。

### 雷区 4：首次启动未展示隐私政策授权弹窗
- 平台审核员在真机首次安装打开时，必须看到清晰的「服务协议与隐私政策」弹窗，用户点击「同意」后方可进入主界面。

### 雷区 5：APK 签名信息与后台登记不一致
- 每次打包必须使用相同的正式发布密钥 `shubu_release.keystore`。
- 后台登记的 SHA256 必须严格与 `store_materials/KEYSTORE_INFO.txt` 中的指纹一致。

## 四、应用截图 (Screenshots) 设计规范建议

各应用市场通常要求上传 3 ~ 5 张 1080×1920 (9:16) 或 1080×2400 竖屏宣传截图。建议结构如下：

1. **第 1 张【核心爆点】**：
   - 顶部大标题：**全自动无感记账**
   - 副标题：微信/支付宝支付秒级识别入账，从此告别漏记
   - 画面：手机展示微信支付完成微浮窗快速补分类界面
2. **第 2 张【极简美学】**：
   - 顶部大标题：**经典纯粹 1:1 交互**
   - 副标题：精简核心分类，自定义计算器软键盘边算边记
   - 画面：主记账界面 + 加减计算器键盘
3. **第 3 张【多维自由】**：
   - 顶部大标题：**四大核心账本与无限自建**
   - 副标题：日常/投资/储蓄独立核算，无 VIP 限制
   - 画面：账本切换抽屉与自建项目账本弹窗
4. **第 4 张【专业金融】**：
   - 顶部大标题：**规范分期与周期记账**
   - 副标题：对齐信用卡与花呗逻辑，每月扣款清晰明了
   - 画面：分期设置详情页与账单日选择
5. **第 5 张【隐私底线】**：
   - 顶部大标题：**100% 纯本地离线隐私**
   - 副标题：零广告 · 零云端上传 · 零商业SDK，数据完全在手机
   - 画面：关于页面 AMOLED 纯黑界面与离线架构标识
